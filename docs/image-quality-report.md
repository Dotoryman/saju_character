# 캐릭터 이미지 품질 점검 — v0.3.0

## 점검 결과

- 점검 대상: R2에 등록된 캐릭터 이미지 129개
- 원본 너비: 225–230px (평균 229.5px)
- 원본 높이: 323–371px (평균 348.9px)
- 평균 파일 크기: 약 88.5KB

원본은 모두 세로형 캐릭터 이미지로 구성되어 있지만, 큰 영역에 확대하기에는 해상도가 낮다.

## v0.3.0 적용 사항

- 데스크톱 카드의 이미지 표시 너비를 최대 184px로 제한했다.
- 모바일 카드의 이미지 표시 너비를 120px로 제한했다.
- 원본 비율에 가까운 `2:3` 프레임과 `object-fit: cover`를 사용했다.
- 이미지가 카드 전체를 차지하도록 확대하던 구조를 제거했다.
- 테두리, 그림자, 하단 그라데이션을 사용해 작은 원본에서도 선명한 인상을 유지했다.

현재 이미지 파일은 교체하지 않고 R2 원본을 그대로 사용한다. 이후 더 큰 원본을 확보하면 같은 경로에 교체하는 것만으로 UI 수정 없이 품질을 높일 수 있다.
